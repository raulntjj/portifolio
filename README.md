# Portfólio - Raul Teodoro

Este é o portfólio pessoal de Raul Teodoro, desenvolvedor Full Stack especializado em PHP, Laravel, .NET e tecnologias modernas.

## Sobre o Projeto

Este portfólio foi desenvolvido com React, TypeScript, Tailwind CSS e GSAP para animações, apresentando minhas habilidades, experiências e projetos de forma interativa e moderna.

**Repositório**: https://github.com/raulntjj/portifolio-raulntjj

## Desenvolvimento Local

Para executar o projeto localmente:

```sh
# Clone o repositório
git clone https://github.com/raulntjj/portifolio-raulntjj.git

# Navegue até o diretório do projeto
cd portifolio-raulntjj

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Tecnologias Utilizadas

- Vite
- TypeScript
- React 18
- shadcn-ui
- Tailwind CSS
- GSAP (GreenSock Animation Platform)
- Radix UI Components
- Lucide React Icons
